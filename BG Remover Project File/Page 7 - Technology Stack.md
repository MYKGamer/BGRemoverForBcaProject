# TECHNOLOGY STACK

The project is built using a modern full-stack architecture, focusing on performance, security, and developer efficiency.

| Technology | Role | Purpose |
| :--- | :--- | :--- |
| **Next.js 14+** | Framework | Core application framework (App Router) for React. |
| **Tailwind CSS** | Styling | Utility-first CSS framework for rapid and responsive UI design. |
| **Shadcn UI** | UI Components | High-quality, accessible UI components (Buttons, Modals, Toasts). |
| **Supabase** | Backend/DB | Handles Authentication, PostgreSQL Database, and Cloud Storage. |
| **Clipdrop API** | AI Engine | External API that performs the actual background removal. |
| **Razorpay** | Payments | Secure payment gateway for credit top-ups. |
| **Lucide React** | Icons | Modern and lightweight icon set for the UI. |

### Why This Stack?
*   **Performance:** Next.js provides server-side rendering (SSR) for fast initial loads.
*   **Scalability:** Supabase (built on PostgreSQL) ensures the data can scale with user growth.
*   **Security:** Authentication is handled by industry-standard Supabase Auth.
*   **User Experience:** Tailwind and Shadcn allow for a consistent and "premium" design system.
