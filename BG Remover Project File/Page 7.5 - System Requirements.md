# SYSTEM REQUIREMENT SPECIFICATION (SRS)

A crucial phase of any software development is determining the hardware and software requirements. Since this project follows a Cloud-based SaaS model, the client-side requirements are minimal, while the development environment requires specific tools.

### 1. Software Requirements (Development Environment)
*   **Operating System:** Windows 10/11, macOS, or Linux.
*   **Programming Language:** TypeScript / JavaScript (ES6+).
*   **Frameworks:** React.js, Next.js 14+ (App Router).
*   **Database:** PostgreSQL (Managed via Supabase).
*   **Code Editor:** Visual Studio Code (VS Code).
*   **Version Control:** Git & GitHub.
*   **API Testing Tool:** Postman (for API validation).

### 2. Hardware Requirements (Development Environment)
*   **Processor:** Intel Core i3 (10th Gen) / AMD Ryzen 3 or higher.
*   **RAM:** Minimum 8 GB (16 GB recommended for smooth Next.js compilation).
*   **Storage:** 256 GB SSD (Minimum 5 GB free space).
*   **Internet:** High-speed broadband connection (Mandatory for Cloud DB & APIs).

### 3. Client/User Requirements (End-User)
Since the application is hosted on the cloud and rendered in the browser, users only need:
*   **Device:** Any PC, Mac, Tablet, or Smartphone.
*   **Web Browser:** Google Chrome, Mozilla Firefox, Safari, or Microsoft Edge (Updated versions).
*   **Internet:** Active internet connection to upload images and access the dashboard.
*   **Storage:** Minimal local storage for downloading processed PNG files.
